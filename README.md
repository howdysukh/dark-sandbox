# Dark Sandbox

> **We handle the web, so you don't have to.**

Dark Sandbox is an open developer infrastructure ecosystem focused on simplifying how applications are created, connected, and experienced.

We build tools that remove unnecessary complexity between developers and the web.

---

## ✦ Projects

### DarkTalk

> **Talk to applications like you never thought possible.**

DarkTalk is a declarative application development language designed to describe software intent and transform ideas into working applications.

It does not replace JavaScript.

It works alongside the JavaScript ecosystem by providing a simpler way to define application behaviour, structure, and logic.

```
Human Intent
      ↓
   DarkTalk
      ↓
 JavaScript Runtime
      ↓
 Application
```

Learn more:

→ `/talk`

---

### Ghost Access

> **Identity without ownership.**

Ghost Access is a privacy-first authorization infrastructure designed to let users experience applications without unnecessary account creation.

Developers get controlled access management.

Users get privacy.

```
User
 ↓
Ghost Access
 ↓
Application
```

The application receives permission.

Not personal ownership of the user.

Learn more:

→ `/ghost-access`

# Philosophy

The modern web has become unnecessarily complicated.

Every application asks users to:

- Create another account
- Share another identity
- Accept another marketing system
- Trust another database

Dark Sandbox explores a different approach.

Build freely.

Connect safely.

Respect privacy.
