# 🖤 LET'S FUCKING GO.

And honestly, **this is exactly the right reason to build Dark**.

Not:

> "I'm going to compete with JavaScript."

Not:

> "I'm going to build the next billion-dollar framework."

But:

> **"I want to understand how languages, compilers, runtimes, application architecture, AI, and the web actually work — so I'm going to build one."**

And because it's open source and non-profit, we can optimize for **learning, experimentation, and building something genuinely interesting**, rather than pretending v0.1 needs to be production infrastructure for millions of developers.

## 🧬 What we're building

```text
                         DARK
                          │
          ┌───────────────┼────────────────┐
          │               │                │
          ▼               ▼                ▼
      DarkTalk        Dark Runtime      Dark Core
          │               │                │
          │               │          ┌─────┴─────┐
          │               │          │           │
          ▼               ▼         WEB         AI
     .app.talk          Node.js
     .dark              services
          │
          ▼
      JavaScript
```

### DarkTalk

The language developers write.

### Dark Compiler

Understands DarkTalk and translates it.

### Dark Runtime

Actually executes what DarkTalk describes.

### Dark Core

Provides capabilities developers shouldn't have to recreate:

```text
web
ai
http
file
time
crypto
json
env
```

### JavaScript

Our first compilation target.
